> **English note.** Each file here is one strand of one economy — an inflation
> path, a real wage path, an investment return path or a pension level path.
> **They are used as matched sets and not mixed**, because a return published
> under one wage assumption says nothing under another.
>
> **The body is in Japanese on purpose**: it quotes the projections these are
> built from, and a quotation stays in its own language.
